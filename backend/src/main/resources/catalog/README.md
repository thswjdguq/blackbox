# 국내 대학·학과 오프라인 목록

출처: 한국대학교육협의회 / 공공데이터포털 [전국대학별학과정보표준데이터](https://www.data.go.kr/data/15107737/standard.do).

- 다운로드: 2026-10-19. 자료 연도 2025, 데이터 기준일 2026-03-18.
- 공식 다운로드 페이지의 StdDownloadManager가 사용하는 `/download/columList.json?pk=15107737&ext=JSON` 및 `/download/standard.json`을 사용했다. API 키가 필요한 운영 Open API가 아니라 공개 파일 다운로드이다.
- 10,000행씩 11페이지, 마지막 1,238행을 확인. 원본 101,238행.
- 학위 학사/전문학사/학석사통합, 대학원 유형 제외, 상태 기존/신설/변경/통합/분리만 포함. 폐과 제외.
- 학교명·시도·학교유형으로 묶고 같은 학교의 중복 학과명을 합쳤다. 이 조합 기준 학교 447개, 학과 15,189개. 캠퍼스 공식 식별자나 정부 학교코드를 제공하는 목록으로 해석하지 않는다.
- `sch_`, `dep_` ID는 조합의 SHA256 일부에서 생성한 앱 내부 식별자이다. 공식 기관 코드가 아니다.
- 재생성: 공식 다운로드 JSON을 `page-1.json`부터 마지막 페이지까지 내려받은 후 `node scripts/build-university-catalog.cjs <페이지 폴더>` 실행. 원본 전체 파일은 빌드 폴더에만 보관하고, 필요한 학교/학과명만 담은 결과 스냅샷을 추적한다.
- 현재 존재·재학 여부를 인증하지 않는다. 갱신 지연/누락에 대비해 직접 입력을 별도 SELF_REPORTED로 허용한다. 외부 서비스 없이 런타임 조회/검증한다.
