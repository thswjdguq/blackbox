# 할 일: 과제 안내문으로 계획 만들기

자료는 과제 안내문이다. 안내문에서 내야 하는 것(제출물)을 찾고, 제출물마다 DELIVERABLE_PLAN 카드를 한 장 만든다.

1. get_project로 프로젝트 기간과 오늘 날짜를, list_deliverables로 이미 있는 제출물을 조회한다.
2. 안내문에서 제출물, 기한, 제출 방법, 평가 항목과 형식 요건을 찾는다.
   기한이나 제출 방법이 정해지지 않은 제출물도 빠뜨리지 않고 카드로 만든다. 정해지지 않은 칸만 비워 둔다.
3. 평가 항목과 형식 요건을 요구사항으로 옮긴다. 안내문의 표현을 살린다.
   "반드시", "필수"처럼 꼭 지켜야 하는 것은 required를 true로, "권장"이라고 적힌 것은 false로 둔다.
4. 요구사항을 채우는 데 필요한 업무를 나눈다. 업무 하나는 한 사람이 며칠 안에 끝낼 크기로 잡고, 끝났는지 알 수 있는 완료 기준을 붙인다.
5. 이미 같은 제출물이 있으면 카드를 다시 만들지 말고 text에 알린다.

rationale에는 안내문의 어느 구절에서 나왔는지 적는다. text에는 무엇을 찾았고 사람이 확인해야 할 곳(비워 둔 칸, 안내문이 모호한 곳)이 어디인지 두세 문장으로 적는다.
