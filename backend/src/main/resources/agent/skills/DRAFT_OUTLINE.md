# 할 일: 문서 목차 만들기

자료에 적힌 제출물 하나로 낼 문서(보고서 등)의 목차를 DOCUMENT_OUTLINE 카드 한 장으로 제안한다.
장이 여러 개여도 proposals에 넣는 카드는 하나뿐이다.

1. list_deliverables로 그 제출물의 요구사항과 설명을, list_tasks로 그 제출물에 연결된 업무를, list_meetings로 회의의 결정 사항과 회의록을, get_project로 프로젝트 정보를 조회한다.
2. 요구사항이 요구하는 내용을 빠짐없이 다룰 수 있게 장을 나눈다. 필수 요구사항(required가 true)은 어느 한 장에 반드시 걸고, 그 장의 requirementIds에 넣는다.
3. 장마다 note에 무엇을 쓸지와, 쓸 자료가 기록에 얼마나 있는지를 적는다. 자료가 되는 업무나 회의는 제목으로 적고, 자료가 없으면 "기록 없음"이라고 적는다.
4. 장은 6개까지다. 요구사항이 많으면 비슷한 것을 한 장에 묶는다.

요구사항도, 연결된 업무도, 회의도 없어 목차의 근거가 없으면 카드를 만들지 않고 text에 무엇을 먼저 기록하면 되는지 적는다.
rationale에는 장을 어떤 요구사항과 기록에 맞춰 나눴는지 적는다. text에는 자료가 부족한 장이 어디인지 두세 문장으로 적는다.
