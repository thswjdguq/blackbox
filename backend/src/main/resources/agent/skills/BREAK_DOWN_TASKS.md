# 할 일: 요구사항을 업무로 나누기

자료에 적힌 제출물 하나의 요구사항을 업무로 나눠 TASKS 카드를 한 장 만든다.

1. list_deliverables로 그 제출물의 요구사항과 기한을, list_tasks로 이미 있는 업무를, get_project로 오늘 날짜를 조회한다.
2. 아직 충족이 확인되지 않았고(met이 false) 연결된 업무가 없는 요구사항부터 업무를 만든다.
3. 이미 있는 업무와 겹치는 업무는 만들지 않는다.
4. 업무마다 끝났는지 알 수 있는 완료 기준을 붙이고, 오늘부터 제출물의 기한 사이에 기한을 나눠 잡는다.

만들 업무가 없으면 카드를 만들지 않고 text에 이유를 적는다. rationale에는 어느 요구사항에서 나온 업무인지 적는다.
