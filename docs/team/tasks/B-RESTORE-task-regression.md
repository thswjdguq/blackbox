## 목적

## 완료 기준
- 확정/제출된 최종 제출물에 연결된 업무의 수정·삭제·이동·담당자 변경·신규 연결 거절, 기존 자료와 활동 기록 보존.
- 관찰자·비회원·미로그인 차단, 연결되지 않은 업무 수정 허용.
- 업무 완료와 검토 피드백 해결의 구분, 미해결 피드백이 남은 최종 확정 차단.
- 서로 다른 트랜잭션의 확정/피드백 재개 경쟁, 연결 변경 대기, 반대 방향 업무 이동 검사.
- 전용 DB에서 검사 결과를 PR과 handoff에 기록한다. 전체 통합/브라우저/학교 AI 검증은 별도다.

## 검사 환경
- 전용 PostgreSQL DB: blackbox_test_db 컨테이너의 bb_b_restore_20261026.
- Java 17 컨테이너에서 두 테스트 클래스 실행. 시연·운영 DB는 사용하지 않는다.
- 기존 동시성 검사의 정리는 해당 테스트가 만든 프로젝트 ID에만 적용된다. 기존 file_vault 정리의 트리거 일시 해제는 전용 검사 DB의 같은 트랜잭션 안에서 수행한다.
