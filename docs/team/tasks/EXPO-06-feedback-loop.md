# EXPO-06 피드백과 개인 알림 연결

2026-10-19 사용자 요청. 기준 shinguexpo / cb23907d. 기존 미커밋 수정은 보존한다.

- 업무 상세의 일반 댓글도 팀원에게 알리고 피드백함에 표시한다. 명시적으로 지정한 의견 요청은 지정 수신자만 받는다.
- 일반 댓글에도 답글을 허용하고 원 작성자에게 알린다. 답변한 요청도 목록에서 지우지 않는다.
- 결과 파일 등록은 기존 팀원 알림을 유지한다. 파일 등록/답변을 실제 반영 완료로 자동 판정하지 않는다.
- 최종 제출물 검토 피드백과 반영 기록도 같은 피드백함·개인 알림으로 연결한다. DB 확장이 필요하며 번호/소유 경계 확인 후 진행한다.
- 관찰자·본인 알림 제외, 프로젝트 경계, 원문과 파일 기록, 트랜잭션 원자성을 유지한다.
- 별도 테스트 DB에서 검증한다. 커밋·push·배포는 이번 범위에 포함하지 않는다.
