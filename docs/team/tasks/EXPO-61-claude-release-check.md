# EXPO-61 · 새 이미지 최종 확인 및 현장 점검 준비

## 사용자 확정: 실제 AI 시연 필수

2026-10-17 사용자 답변으로 AI 실연동을 엑스포 필수 범위에 포함했다. AI를 끈 수동 흐름만으로 전시 준비 완료라고 판정하지 않는다.

- 통합본 `.env`에 OPENAI_API_KEY 항목이 채워져 있는 사실만 확인했다. 유효성·공급자·모델은 아직 미확인이다. 키를 출력하거나 다른 공급자에게 시험 전송하지 않는다.
- 사용자에게 학교 게이트웨이/직접 연결 여부와 주소·모델을 질문한 상태다. 연결 대상이 확정되면 해당 환경의 키로 최소 합성 자료만 사용해 검증한다.
- 실제 모델 응답 → UI 스트리밍 종료 → 제안 검토·사용자 채택 → 실제 업무 반영까지 확인한다. 도구 호출을 포함해 모델 요청 횟수를 기록하고 무제한 재시도하지 않는다.
- 중단·오류·시간 초과 시 진행 중 상태가 해제되고 기존 업무/입력이 보존되는지 확인한다. 401/429/시간 초과 검사는 통제된 mock 또는 별도 검증 환경으로 수행하고 실공급자 과부하를 만들지 않는다.
- 로컬/격리 HTTPS의 AI 검증과 공개 주소에서의 AI 검증을 구분한다. 공개 주소 및 실제 휴대폰 확인은 여전히 남아 있다.
