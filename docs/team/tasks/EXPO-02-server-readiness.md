- 배포 준비물: C:\blackbox\outputs\expo-release-20261018. 이미지 태그는 expo-20261018-1eb57b2c-wf8e2c0cc입니다. 로컬 이미지 3개만 빌드된 상태이며 원격 레지스트리 업로드나 AWS 적용은 하지 않았습니다. 이전 latest 이미지를 대신 쓰지 마세요.
- 실제 배포·서버 재시작·보안 그룹 변경은 담당자의 실행 승인 범위를 확인한 뒤 진행하세요. 먼저 기존 데이터와 업로드 파일 백업, 복구 방법 및 현재 이미지 태그를 확보하세요. 볼륨 삭제, 기존 migration 변경, 실제 데이터 정리는 금지합니다.
- 서버 DB_PASSWORD/JWT_SECRET과 AI 키는 서버에서 안전하게 설정하고 출력·커밋하지 마세요. 로컬 .env의 OpenAI 키로 실제 AI는 검증됐지만 서버에 전달된 상태는 아닙니다. LLM_BASE_URL=https://api.openai.com, LLM_MODEL=gpt-4o-mini가 로컬 검증 조합입니다.
- 배포 후 공개 HTTPS 로그인, 4인 업무/피드백/완료 확인/최종 제출 기록, 한글 파일 다운로드, 권한 차단, AI 응답 스트리밍과 제안 적용을 확인하세요. 비용이 발생하는 AI 검사는 합성 데이터로 최소 횟수만 실행하세요.
- 실제 휴대폰 모바일 데이터로 QR 접속, 로그인, 파일 확인을 검사하세요. 에뮬레이션 결과를 실제 기기 검사로 기록하지 마세요.
- 승인된 재시작 후 DB와 업로드 파일 보존도 확인하세요. 기존 검증 결과와 이번 실측 결과를 구분해 handoff에 남기세요.

공개 접속 및 실제 휴대폰 확인 전에는 전시 준비 100% 완료로 보고하지 마세요.
