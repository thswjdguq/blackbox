# EXPO-10 — 회원가입 학교·학과 및 직접 입력

사용자 요청: 국내 대학/전문대 및 학교별 학과 선택. 공식 자료 지연에 대비한 직접 입력 허용. DB migration 번호 충돌 확인 필수.

- 기준: shinguexpo / e8f41aad + 기존 EXPO-09 미커밋 수정 보존.
- 범위: 공식 공개 파일 스냅샷·변환 도구, 검색 API, 회원가입·프로필 소속 저장, 신규 migration, 선택/직접 입력 UI와 검증.
- 직접 입력은 SELF_REPORTED로 구분하며 재학 인증을 의미하지 않는다. CATALOG도 공식 목록 일치 여부일 뿐 재학 인증이 아니다.
- 기존 회원의 소속은 NULL로 유지. 기존 migration 변경/삭제 금지.
- 2026-10-19 확인: 최신 github/main V25, 로컬 V31_1, 열린 PR #133 V32 예약. 미사용 V31_2(31.2)를 이 작업에서 사용해 V31_1 → V31_2 → V32 순서를 지킨다. V23은 별도 예약으로 사용하지 않는다. 다른 DB/브랜치 통합 전 다시 확인한다.
- 이미 V32 이상인 DB에는 이 분기를 바로 적용하지 않는다. 공개 서버 적용 전 실제 Flyway 이력 확인이 필요하다.
- 학교/학과 선택은 ID 조합을 서버 검증. 직접 입력은 별도 경로에서 길이 및 빈 값 검증.
- 별도 검증 DB에서 기존 사용자 보존·실제 회원가입 HTTP 검증 후 로컬 실행본 반영. 커밋/push/운영 배포는 범위 밖.
