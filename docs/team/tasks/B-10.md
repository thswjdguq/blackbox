## 범위와 완료 기준

1. K-13의 조회 경로와 권한을 구현하고 업무 진척·필수 요구사항 수를 분리한다.
2. 없는 충족 확인 데이터를 0%/완료로 조작하지 않는다. 합의된 미지원/null 정책을 사용한다.
3. 0건, 소수 반올림, 다른 프로젝트/제출물, 여러 담당자, 관찰자·비회원을 검증한다.
4. Controller 응답/오류와 서비스 계산을 구분해 검사한다. 서비스 mock 테스트를 실제 인증/DB 검증으로 보고하지 않는다.
5. 관련 Gradle 테스트·compileJava 통과 및 남은 DB 통합 검증을 기록한다.
