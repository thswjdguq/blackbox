- 작은 화면에서 줄 더하기·지우기 버튼은 44px

확인 16/16 (Edge headless, 실제 서버의 제출물·요구사항 + `/status`·`/proposals` 대역). 이 확인에서 **"계속 고치기"를 누르면 저장이 나가던 버그**를 찾아 고쳤다. 확인 줄과 버튼 줄이 같은 자리라 React가 "계속 고치기" 버튼 요소를 submit "저장"으로 다시 써서, 클릭이 끝날 때 폼이 제출됐다. 두 줄에 다른 key를 준다.
