# EXPO-04 프로젝트 삭제 오류·업무 수정 진입 개선

- 2026-10-19 사용자 요청. 기준 shinguexpo cb23907d. 기존 footer 변경 보존.
- 재현: 로컬 서버의 프로젝트 삭제에서 Hibernate TransientObjectException 발생. 권한 확인 중 읽은 멤버가 삭제된 Project를 참조한다.
- 허용 범위: ProjectRepository/Service와 삭제 회귀 테스트, TaskModal 및 업무 목록의 수정 진입 표시, 개별 인수인계. 기존 파일·활동 기록 보존 제약 및 서버 권한 유지. migration/점수 산식 변경 없음.
- 업무의 수정·삭제는 기존 API와 화면에 구현돼 있다. 숨은 업무 설정 탭을 수정·삭제로 명확히 표시하고 요청 대기·완료 시 재개 절차를 안내한다. 별도의 CANCELLED 상태를 임의 추가하지 않는다.
- 합성 테스트 데이터만 생성·삭제해 검증한다. 사용자의 실제 프로젝트는 삭제하지 않는다.
