## 동작

- 연동 상태·가용 시간·시간 추천은 프로젝트 멤버만 조회한다.
- 일정 등록은 프로젝트 팀장·팀원만 가능하고 참석자 전원을 같은 프로젝트에서 검증한 뒤 외부 API를 부른다.
- OAuth state는 사용자 ID 대신 10분 만료의 난수를 쓴다. 서버의 발급 기록과 HttpOnly/SameSite=Lax 쿠키, 로그인 사용자가 있으면 동일 계정인지도 확인하고 한 번만 소비한다.
- 서버 재시작이나 여러 서버 사이에서 발급 기록이 없으면 안전하게 거절하고 연동을 다시 시작한다. 현재 단일 백엔드 범위이며 영속 저장소를 새로 만들지 않는다.
- URL·JSON 응답 모양은 유지한다. callback은 기존처럼 로그인 토큰이 만료돼도 해당 브라우저에서 시작한 유효한 연동만 완료할 수 있다.

- 정상 멤버 조회, 관찰자 쓰기 거절, 타 프로젝트/없는 참석자 전체 요청 거절, 중복 참석자 정규화.
- OAuth 변조·쿠키 누락·다른 브라우저/계정·만료·재사용·동시 소비 거절 및 쿠키 보안 속성.
