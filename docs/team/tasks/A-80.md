# A-80 · 여러 결과로 나뉜 모델 응답의 결합

- 담당: 송승준 / 검토: 손정협, 손정효
- 기능: S2 (AI 에이전트)
- 상태: IN_REVIEW
- 기준 SHA: `63ead3fd`(#234 병합)

## 문제

A-79의 실제 모델 검사(`DocumentDraftLiveTest`, Gemini `gemini-3.5-flash-lite`)에서 초안 실행이 "답이 JSON 객체 하나가 아니다"로 실패했다. 받은 응답은 근거 id 중간에서 끊겨 있었는데, 모델 호출 기록의 종료 이유는 출력 상한이 아니라 정상 종료(`STOP`)였다. 형식을 고쳐 달라는 재요청의 응답도 1,142 토큰을 출력했다고 기록됐지만 받은 글은 277자였다.

## 원인

Spring AI 2.0.2의 `GoogleGenAiChatModel.responseCandidateToGeneration`은 모델 응답의 글 조각(part)마다 결과(`Generation`)를 하나씩 만든다. `SpringAiAgentModel.generate`는 첫 결과(`ChatResponse.getResult()`)의 글만 읽어, Gemini가 응답을 여러 조각으로 보내면 첫 조각 뒤가 버려졌다. 지금까지의 실행 종류에서 드러나지 않은 것은 응답이 짧아 한 조각으로 왔기 때문으로 보인다.

## 수정

- `SpringAiAgentModel.text`: 결과를 순서대로 이어 붙인다. Gemini가 추론(thinking) 조각에 붙이는 `isThought` 표시가 있는 결과는 넣지 않는다. 후보 응답을 여러 개 청하지 않으므로 이어 붙여도 다른 응답이 섞이지 않는다
- OpenAI 호환 API는 선택지(choice) 하나가 결과 하나라 바뀌는 것이 없다. 운영은 이 방식으로 Bedrock에 붙는다(`docs/deploy-aws.md` 10장)
- 공급자 `bedrock-converse`(`BedrockProxyChatModel`)도 글 블록마다 결과를 만들어 같은 결함이 생길 수 있었고, 이번 수정으로 함께 이어 붙는다. 이 공급자는 실제 모델로 확인하지 않았다

## 검사

- `SpringAiAgentModelTest` 1건 추가: 추론 조각, 글 조각 둘, 빈 도구 호출 자리로 나뉜 응답을 이어 붙여 추론 조각 없이 돌려준다
- 실제 모델 검사: A-79의 `DocumentDraftLiveTest`를 이 수정과 함께 Gemini로 두 번 실행했으나, 두 번 모두 목차 실행 중 Gemini가 503(요청 혼잡)으로 응답해 확인하지 못했다. 다시 실행해 결과를 남긴다
