## 문제

A-79의 실제 모델 검사(`DocumentDraftLiveTest`, Gemini `gemini-3.5-flash-lite`)에서 초안 실행이 "답이 JSON 객체 하나가 아니다"로 실패했다. 받은 답은 근거 id 중간에서 끊겨 있었는데, 모델 호출 기록의 종료 이유는 출력 상한이 아니라 정상 종료(`STOP`)였다. 형식을 고쳐 달라는 재요청의 답도 1,142 토큰을 출력했다고 기록됐지만 받은 글은 277자였다.

## 원인

Spring AI 2.0.2의 `GoogleGenAiChatModel.responseCandidateToGeneration`은 모델 답의 글 조각(part)마다 결과(`Generation`)를 하나씩 만든다. `SpringAiAgentModel.generate`는 첫 결과(`ChatResponse.getResult()`)의 글만 읽어, Gemini가 답을 여러 조각으로 보내면 첫 조각 뒤가 버려졌다. 답이 짧아 한 조각으로 오면 문제가 드러나지 않는다.

## 수정

- `SpringAiAgentModel.text`: 결과를 순서대로 이어 붙인다. Gemini가 생각(thinking) 조각에 붙이는 `isThought` 표시가 있는 결과는 넣지 않는다. 후보 답을 여러 개 청하지 않으므로 이어 붙여도 다른 답이 섞이지 않는다
- OpenAI 호환 API와 Bedrock은 답 하나가 결과 하나라 바뀌는 것이 없다

## 검사

- `SpringAiAgentModelTest` 1건 추가: 생각 조각, 글 조각 둘, 빈 도구 호출 자리로 나뉜 응답을 이어 붙여 생각 조각 없이 돌려준다
- 실제 모델 검사: A-79의 `DocumentDraftLiveTest`를 이 수정과 함께 실행해 확인한다(아래 결과)
