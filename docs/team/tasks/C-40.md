## 목표

휴대폰(폭 390px)에서 화면이 가로로 밀리지 않고 메뉴로 이동할 수 있게 한다. S5(등록·확인·검토 주요 화면을 작은 화면에서 사용)의 바탕 작업이다. Task ID는 계획표에 없어서 임시로 C-40을 썼다.

## 문제

- 사이드바가 늘 256px을 차지하고 본문이 `ml-64`로 밀려 있어 휴대폰에서는 본문이 134px만 남았다.
- 제출물 상세 탭 이름이 글자 단위로 줄바꿈됐다.
- 업무 보드 상단 통계가 한 글자씩 세로로 찌그러졌다.
- 업무 보드 전체가 `min-w-[900px]`라 필터 줄과 팀원별 현황이 화면 밖으로 잘렸다.
- 대시보드·기여도 분석·회의록 상세의 머리 버튼("새 프로젝트", "재계산", "AI 요약" 등)과 일정 조율의 "2시간 이상"이 두 줄로 찌그러졌다.

## 변경

| 화면 | md(768px) 미만 | md 이상 |
|------|------|------|
| 사이드바 | 상단 바(56px)의 메뉴 버튼으로 여닫음. 메뉴를 고르거나(지금 화면 포함) 배경·Escape로 닫힘. 열면 닫기 버튼에, 닫으면 메뉴 버튼에 초점. 닫혀 있으면 Tab 초점이 가지 않음 | 기존과 같음 |
| 본문 22곳 | 왼쪽 여백 없음, 상단 바 아래에서 시작, 안쪽 여백 16px | 기존과 같음 (`ml-64`, `p-8`) |
| 제출물 상세 탭 | 탭 줄만 가로로 넘김, 탭 이름은 한 줄 | 기존과 같음 |
| 업무 보드 | 상단 통계 줄바꿈. 세 열만 가로로 넘기고 필터·팀원별 현황은 화면 폭에 맞춤 | 기존과 같음 (900px 이상) |
| 대시보드·기여도·회의록 상세 머리 | 버튼 줄이 제목 아래로 내려가고 버튼 글자는 한 줄 | 기존과 같음 |
| 일정 조율 소요 시간 | 3열 | 5열 (기존과 같음) |

알림 종은 사이드바 안에만 둔다. 상단 바에 하나 더 두면 같은 알림을 두 번 조회한다.

## 확인

Edge headless, 실제 서버, 390×844(터치)와 1440×900. 54/54 (#63 병합 뒤 main을 받아 다시 실행).

- 휴대폰 12개 화면(대시보드·프로젝트 홈·제출물 목록·상세·보드·설정·회의록·회의록 상세·일정 조율·기여도·Hash Vault·프로필 설정): 페이지 가로 스크롤 없음, 사이드바 숨김, 10자 이하 버튼·링크·탭 글자가 두 줄로 나뉘지 않음(글자 줄 상자 위치로 판정)
- 휴대폰: 메뉴 열기 → 메뉴에서 이동하면 닫힘, 배경 누르면 닫힘, 본문이 상단 바 아래에서 시작
- 휴대폰(B 리뷰 반영): 지금 화면(제출물) 메뉴를 눌러도 닫힘, 아래쪽 메뉴(프로필 설정)로 이동해도 닫힘, 열면 초점이 "메뉴 닫기", Escape로 닫히고 초점이 "메뉴 열기", 닫힌 메뉴는 visibility hidden이고 Tab 초점이 들어가지 않음, 프로젝트 선택 전 막힌 메뉴는 대시보드에 머묾
- #63 업무 보드 관찰자 확인(ui01)도 병합 뒤 다시 실행해 20/20
- 휴대폰 보드: 제출물 관리 링크와 팀원별 현황이 화면 안, 열 영역만 가로로 넘김
- 데스크톱: 사이드바 고정, 상단 바 없음, 본문 256px 오른쪽, 보드 세 열이 넘치지 않음
- 스크린샷으로 각 화면 배치 확인
