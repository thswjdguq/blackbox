- 허용: frontend 화면/문구/검사, scripts/start-local-expo.ps1, 개별 작업/인수인계. API·DB·의존성·migration 변경 없음.

- 공개 주소/인증서·실제 휴대폰 모바일 데이터·현장 재부팅은 외부 환경이 필요한 별도 완료 조건. 공개 배포 권한을 추정하지 않는다.
