6. **squash merge를 유지할지** — squash는 PR의 커밋을 하나로 합치므로 레이어별로 쪼갠 커밋이 main에 남지 않고
   부분 롤백도 불가능하다. 대신 main 히스토리가 PR 단위로 단순해진다. squash를 유지하면 PR 자체를 작게 나눠야 하고,
   merge commit으로 바꾸면 커밋이 보존되는 대신 히스토리가 복잡해진다. squash일 때 main에 남는 문장은
   개별 커밋문이 아니라 **PR 제목**이므로, 제목에도 커밋 규칙을 적용한다.
