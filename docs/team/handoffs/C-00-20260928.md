| 화면 | 로딩 | 0건 | 권한 없음 | 저장 실패 | 재시도 | 저장 성공 |

알려진 부족한 점:

- 제출물 목록·상세의 불러오기 실패는 403·404·500을 구분하지 않고 같은 문구다. 404일 때 서버 detail 표시는 A-05(#56) 병합 후 상세 화면에 적용한다.
- 비회원이 URL로 직접 들어온 경우의 화면은 브라우저로 확인하지 않았다.

## 4. 멤버 관리 API 연결

| API | 서버 코드 | 화면 연결 | 실제 동작 확인 |
| --- | --- | --- | --- |
| `GET /projects/{id}/members` | 있음 (`ProjectController.listMembers`) | 설정 > 멤버 목록, 프로젝트 홈 아바타 | 미확인 |
| `PATCH .../members/{memberId}/role` | 있음, 팀장만, 마지막 팀장 강등 403 | 설정 > 역할 선택 (팀장에게만). 마지막 팀장은 강등 옵션 비활성 | 미확인 |
| `DELETE .../members/{memberId}` | 있음, 팀장만, 자기 자신 403 | 설정 > 내보내기 (확인 후). 본인 행에는 버튼 없음 | 미확인 |
| `DELETE .../members/me` | 있음, 혼자 남은 팀장 403 | 설정 > 프로젝트 나가기 (확인 후 대시보드). 혼자 남은 팀장은 버튼 비활성 + 이유 안내 | 미확인 |

"미확인"은 코드가 없다는 뜻이 아니라 실제 서버에 요청해 보지 않았다는 뜻이다.
