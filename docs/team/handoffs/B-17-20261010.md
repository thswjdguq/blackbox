# B-17 리뷰 반영 결과

담당 손정협(B). 기준 main `5aa2877`. PR #100은 이미 병합되어 후속 테스트 PR로 반영한다.

## 반영한 내용

- A의 리뷰 1번: 테스트 컨텍스트에서 ScoreScheduler를 mock으로 격리했다.
- 추가로 대조 중 발견: 스케줄러만 격리해도 성공 검사가 옛 코드에서 통과했다. AlertService 자체의 트랜잭션이 계산 전체의 트랜잭션처럼 관찰되기 때문이다. ScoreService의 내부 재계산 진입 시점으로 관찰을 옮겼다. 외부의 비동기 진입점에서 이미 시작한 트랜잭션이어야 통과한다.
- 리뷰 3번: 종료 시 이번 테스트가 생성한 사용자·프로젝트 UUID에 한정해 점수·활동·업무·멤버 등 검사 자료를 정리한다. 사용자·프로젝트가 남지 않았음을 검사한다. 기존 자료는 대상으로 삼지 않는다.
- 리뷰 2번의 동시 계산 중복 키 경고: 기존 계산의 동시 실행 정책이다. 이 PR에서는 운영 동작과 잠금 정책을 변경하지 않았다. A의 관찰에서는 점수 한 벌이 올바르게 남았고 오류 로그가 추가됐다. 이 결과를 제가 별도로 재현한 것은 아니다. 서비스 동시성 보완은 별도 범위로 남긴다.
