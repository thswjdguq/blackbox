## 구현

목록·작성·해결·다시 열기 API를 구현했다. 권한은 실제 ProjectAccessChecker를 사용한다.
프로젝트·제출물·회차·코멘트 소속을 확인하고 동일 제출물 잠금으로 승인과 피드백 쓰기를 직렬화한다.
승인된 회차 쓰기를 거절하고 신규 작성은 최신 회차에만 허용한다.
업무 완료는 반영 확인 대기일 뿐 자동 해결이 아니다. 중복 해결은 최초 해결자·사유·시각을 유지하고 다시 열기 이전 기록은 활동 기록에 보존한다.
미해결 수 구현을 별도 빈으로 분리해 순환 의존을 막고 A와 합의한 NoCommentsYet만 제거했다.
신규 활동 종류는 FEEDBACK_CREATE/RESOLVE/REOPEN이며 점수 계산은 바꾸지 않았다.

## 수행한 검사

- 관련 단위·standalone MVC 41건 통과. MVC 검사는 인증 필터가 없는 입력·오류 응답 검사다.
- 실제 PostgreSQL 16.13 전용 DB에서 전체 백엔드 테스트 121건 통과. contextLoads, V1~V22 Flyway validation, JPA validation, 실제 피드백 저장·재조회·count·업무 삭제 후 연결만 해제되는 검사 포함.
- 인증 쿠키를 사용한 실제 HTTP 46건 통과. 준비 요청 포함이며 승인/작성 경쟁 4쌍(8요청)을 포함한다. 관찰자 조회/쓰기, 비회원, 미인증, 입력·UUID·없는 회차, trim, 해결·재개, 중복 시각·사유 유지, 미해결 승인 거절, 승인 후 쓰기 거절, 과거 회차 작성 거절을 확인했다.
- 경쟁 4쌍은 작성 201/승인 409 또는 작성 409/승인 200만 허용했고 위반은 없었다. 양쪽 요청 모두 성공하는 결과는 거절한다.
- 최초 HTTP 검사에서 재요청 해결 시각 정밀도 차이가 발견돼 PostgreSQL 마이크로초 정밀도로 맞춘 뒤 전체 테스트와 HTTP를 다시 실행했다.
- 재현 스크립트 backend/src/test/manual/B20-http.ps1. 검사 전용 서버에서만 실행하며 dummy 계정·프로젝트를 추가한다. 토큰·쿠키는 출력하거나 파일에 저장하지 않는다.

로컬 Gradle 실행 JVM은 25, 애플리케이션 및 테스트 실행 JVM은 로컬 Gradle 도구 체인이 선택한 23.0.2였다. Java 17 검증으로 보고하지 않는다. 원격 CI는 아직 실행하지 않았다.
