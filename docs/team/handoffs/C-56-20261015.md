# C-56 · 대학생 팀플 업무 배정 간소화

## 판단과 로컬 수정

업무 생성 화면이 제출물·요구사항·선행 업무·첨부 필수·태그·체크리스트를 한꺼번에 보여 줘, 대부분 선택값인데도 모두 정해야 할 것처럼 보였다.

기본 화면을 제목 → 담당자 → 마감일 → 결과 기준으로 정리했다. 제목만 필수이며 나머지는 나중에 입력 가능. 결과 기준은 완료 확인 요청 전에는 필요하다는 기존 서버 규칙을 안내한다. 설명·체크리스트·제출물/요구사항 연결·선행 업무·파일 필수·우선순위·태그는 '추가 설정'으로 접었다. 입력을 초기화하거나 기존 조건을 삭제하지 않는다. 활성화된 첨부/선행 조건 및 제출물 연결은 접힌 요약에도 표시한다.

모든 팀원을 담당자로 지정하면 독립 검토자가 없어 완료가 막힐 수 있어 그 선택일 때만 안내한다. 본인 승인·자동 완료로 우회하지 않는다.

## 남은 제품 우선순위

1. 배정받은 업무를 알아차리기: 개인 TASK_ASSIGNED 알림이 필요. Claude 병렬 작업서에 지정.
2. 독립 검토자 0명: 서버가 완료 요청을 받기 전에 해결 가능한 사유를 알려야 함. 서버 담당에게 진단/계약 검토 지정.
3. 최종 파일을 자료실에 별도 업로드한 뒤 검토 화면에서 다시 찾는 흐름 축소. 기존 불변 버전과 본인 검토 금지는 유지.
4. 신규 관람객의 빈 프로젝트 화면과 시연 계정 안내. 자동으로 실제 팀에 가입시키거나 공유 작성 권한을 부여하지 않음.
5. 지연 일수는 사실로 보여 주되 감점은 합의된 초안 검토 전 자동화하지 않음.
