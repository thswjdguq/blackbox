- 테스트 DB `bb_b31`만 사용. 실행 로그에서 현재 V30, migration 추가 적용 없음 확인. 개발 DB·teamplayui 서버·9443 접속 환경은 그대로.
- 테스트 서버: 127.0.0.1:18082. 더미 JWT 및 테스트 전용 DB 자격증명만 사용. 파일 저장도 `C:/blackbox/outputs/b31-http-uploads`로 분리.

- 실행 중 프로세스: frontend exec session 96334, backend 35469. next start가 standalone 권장 경고를 출력했으나 위 HTTP 응답은 확인했다. 기존 배포 설정을 바꾸지 않았다.
