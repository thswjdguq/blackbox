# B-15 비동기 기여도 계산 수정 인수인계

담당 손정협(B). 기준 main `1527927`, 브랜치 `fix/B-15-score-async-transaction`.

## 문제와 변경

PR #97에서 A가 현재 버전과 업그레이드 버전 모두에서 업무 완료 후 자동 계산 실패를 확인했다. ScoreService의 비동기 메서드가 같은 객체의 recalculate를 호출하므로 내부 메서드의 트랜잭션 선언이 적용되지 않는다.

비동기 진입점에 @Transactional을 추가했다. 예외를 경고만 남기고 삼키던 catch를 제거하여 점수·경보를 함께 롤백하고 Spring 비동기 예외 처리기에 전달한다. TaskService의 완료 후 호출, 계산식, 공개 API·권한·DB는 바꾸지 않았다.

## 미검증과 실패 기록

- ScoreAsyncTransactionTest 두 건: 로컬 검사용 PostgreSQL 연결 거부로 컨텍스트 시작 실패. 통과가 아니다. Docker 앱은 실행 중으로 표시되지만 Linux 엔진 소켓이 없고 기존 검사 컨테이너 시작도 실패했다. DB와 볼륨 초기화는 하지 않았다.
- 새 테스트는 실제 TaskService의 완료 커밋과 Spring 비동기 호출을 사용한다. AlertService만 spy로 두어 트랜잭션 종료 상태 관찰 및 의도적 실패를 주입하고, 나머지 저장은 실제 PostgreSQL을 사용한다. HTTP 인증 필터·브라우저 검사는 아니다.
- 전체 backend 테스트, 실제 인증 HTTP·브라우저, #97 업그레이드와의 통합 검증은 아직 수행하지 않았다.
