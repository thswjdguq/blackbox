# 피드백 진행/완료 배치와 내보내기 색상

- 사용자 요청: 진행 중 피드백 상단, 완료 기록은 하단 화살표로 접기/펼치기. 프로젝트 홈 팀 활동 내보내기 색상 정리. 추가 필터는 만들지 않는다.
- 기준 d034c415 + 앞선 EXPO-07 미커밋 변경. 기존 사용자 변경과 선택 마감 시간 작업은 보존한다.
- 허용 범위: C 프론트 피드백 페이지·분류 유틸·기존 피드백 검사, 프로젝트 홈의 내보내기 카드 색상만 변경. API/DB 계약·완료 처리 권한은 변경하지 않는다.
- 받은/보낸 탭 유지. OPINION/ANSWERED와 REVIEW/RESOLVED만 하단 완료 기록. RESPONDED·REFLECTION_PENDING·알 수 없는 상태는 상단 유지한다. 답글이나 업무 완료를 반영 완료로 추정하지 않는다.
- 완료 기록은 기본 접힘, summary에 건수와 방향 화살표. 탭 전환 시 접힘으로 초기화. 원문 링크는 보존하고 최종 제출물 항목의 이동 문구를 수정했다.
- 일반 댓글에는 현재 서버가 별도 완료 명령을 제공하지 않아 답글이 있어도 상단에 유지한다. 완료 확인/보완 항목은 서버가 현재 진행 중인 것만 반환하므로 이번 변경으로 과거 기록을 새로 만들지 않는다.
- 내보내기는 어두운 고정 그라데이션·연보라 배경을 제거하고 surface/border/text 테마 색상 사용. 태그·아이콘은 중립 색상, 다운로드는 흰 글자와 대비되는 진한 파란색 버튼. 다운로드 기능은 유지.
- 검사: npm run type-check 통과. 기존 verify-feedback-loop.cjs는 새 유틸 경로 미등록으로 최초 실패해 실제 유틸을 로드하도록 수정 후 통과. 상태 경계·완료 기본 접힘·상단 분리·원문 이동 검사 포함. git diff --check 통과. 브라우저 실제 조작·모바일·밝은/어두운 테마 화면은 미검증.
- 다음: 로컬 프론트 운영 빌드·갱신, 사용자 화면 확인. 원격 push·merge·공개 서버 배포는 이번 범위에 포함하지 않음. 의존 PR 없음.
- 로컬 결과: Docker 운영 빌드 통과, teamplayui_frontend 갱신 및 nginx reload, 로그인 HTTP 200 확인. 기존 데이터·백엔드 유지. 화면 실제 클릭·테마 전환 검증을 대신하지 않음.
