# EXPO-09 — 완료 기준 선택 처리

사용자 요청에 따라 완료 기준 미작성으로 결과 확인 요청을 막던 검사를 제거했다. 기준 텍스트는 선택 메모로 보존하고, 화면의 필수 작성 안내를 수정했다. DB 변경은 없다.

- 유지: 요청·승인 권한, 본인 승인 금지, 독립 확인자 존재, 선행 업무 승인, 사용자가 설정한 필수 파일, 최종 확정 잠금.
- 검증: TaskWorkflowServiceTest 23/23 통과. null/빈 문자열/공백 기준에서 요청·알림 호출·다른 팀원 승인, 기준 없이도 필수 파일 미충족 차단을 포함한다.
- 프론트: 타입 검사 및 webpack production build 통과. diff 공백 검사 통과.
- 로컬 18083/13000 재시작 및 실제 HTTP 확인: completion 200, checks의 CRITERIA 없음, 로그인 화면 200. 이 HTTP 검사는 기존 합성 계정으로 로그인·조회만 수행했고 프로젝트를 수정하지 않았다.
- 단위 테스트의 알림 검증은 mock 호출 확인이며, 이번 변경 후 실제 다중 계정 브라우저 알림 도착은 별도로 재검증하지 않았다.
- 로컬 수정만 완료. 커밋·push·공개 서버 배포 없음. 기존 next-env.d.ts 부산물과 PR-137 검토 기록 보존.
