- 계약 K-40 0.3 AGREED, #175 B 2번의 독립 가능한 첫 단계.

## 변경

`ScoreReviewActivityReader`가 기존 도메인에서 여섯 종류의 검토 참여 횟수를 읽는다. 현재 팀장·팀원만 반환하고 기록이 없는 기여자도 0을 반환한다. 프로젝트별 멤버 조회와 묶음 집계를 사용한다.

피드백 작성·해결, 회차 결정, 충족 확인, 업무 의견/답글, 업무 결과 승인/보완 요청을 구분한다. 의견 요청과 완료 요청 취소는 횟수에서 제외한다. 업무 재개는 현재 승인을 빼고, 업무 삭제는 사라진 대화를 뺀다. 보완 요청은 기존 활동 기록이므로 남는다. 현재 기여자라면 재가입 전 기록도 포함한다.

호출자의 계산 트랜잭션이 필요한 내부 모듈이다. 점수·판정·경보·HTTP 응답·화면에 아직 연결하지 않았으며 새 공개 기능이 동작하는 상태로 보고하지 않는다. SQL/엔티티 컬럼/라이브러리/A·C 파일/운영 자료는 변경하지 않았다.

## 검사

- Java 25.0.3 / Gradle 9.8.2 / Spring Boot 4.1 / PostgreSQL 16 새 전용 DB `bb_b_score_review_20261112`.
- `ScoreReviewActivityReaderTest` **3/3 통과**, 실패·오류·건너뜀 0. 기대 횟수와 프로젝트 격리, 현재 역할과 재가입 전 기록, 해제·재개·삭제 때 감소 및 보완 이력 보존을 확인했다. 합성 자료는 모두 롤백했다.
- 처음 DB 준비는 PostgreSQL 기동 전 실패해 검사가 시작되지 않았다. `pg_isready` 확인 후 새 DB를 만들어 재실행했다. 로컬 빌드 준비가 오래 걸렸지만 실제 검사 결과는 통과했다(전체 실행 10분 55초).
- migration 이력: 기존 24개 파일 보존, 전체 35개 버전 중복 없음. 이번 SQL 변경 없음. diff 검사 통과.
- 로컬 전체 검사·HTTP·브라우저·유료 AI는 실행하지 않았다. 이 PR 최종 head의 전체 회귀는 GitHub CI에서 확인해 PR에 별도 기록한다.
