## 4. AI 실연동

**미검증.** 18083은 `GET /agent/status` = `available:false, "AI 기능이 설정되지 않았습니다"`. 유료 외부 호출 0회. ASK·상태 요약·계획 제안·채택, 게이트웨이 URL/모델 별칭, SSE·제한시간, 한도/429 안내는 실제 키·게이트웨이가 있는 별도 환경에서 해야 한다. 확인한 것: 미설정 안내 화면, 서버 설정값(`app.agent` 기본 실행 120초·모델 요청 30초·시간당 20회·동시 2회), 실패 문구("OpenAI 요청을 처리하지 못했습니다. 연결과 사용 한도를 확인하세요."). PR127의 Spring AI 공급자와 `OpenAiAgentModel`을 동시에 켜지 않는다(이번에 켜지 않음).

| 고정 QR·모바일 데이터 | 확인 불가(공개 주소 없음) | DuckDNS+Let's Encrypt+Elastic IP 후 휴대폰 데이터망 접속 확인(자체 서명 인증서면 경고 화면) |
| 서버 재시작 복구 | 지시대로 18083/13000 재시작 안 함. 패치 JAR는 새 DB에서 부팅·마이그레이션(V31까지) 성공 | 인스턴스 재부팅 후 자동 기동·자료 유지 확인 |

원격 AWS 배포·DNS·인증서·포트 공개·push/merge는 실행하지 않았다.

## 6. 일요일 동결 전 필수 / 엑스포 이후

**동결 전(필수)**
1. B1 한글 파일명 다운로드 패치 반영 → 재빌드 → 실제 브라우저에서 저장 이름 확인.
2. A1 '무임승차' 알림 처리 결정: 시연 중 숨김, 관찰자 제외, 또는 검토 활동 반영 중 택1(B 담당 확인).
3. AWS에서 AI를 보여 줄 경우 B2 반영. 배포 이미지를 통합본에서 빌드(위 표).
4. B3 날짜 칸 초점(프로젝트·제출물 날짜를 시연에서 직접 입력한다면).

**엑스포 이후로 넘김**: B4·B5, O1~O11(특히 O8 모바일 뒤로가기, O2/O3 잠금 안내, O4/O5 피드백·알림 정리), 이메일·녹음·채팅 연동, 자동 감점.

## 7. 월요일 시작 전 점검 순서

1. 실행: `scripts/start-local-expo.ps1` 또는 배포 서버 기동 → `GET /api/health` 200 → 화면 로그인 페이지 200.
2. 산출물 확인: JAR SHA256이 이 문서/인계 값과 같은지, B1 반영 여부에 맞는 해시인지.
3. 접속: PC 브라우저, 실제 휴대폰(가능하면 모바일 데이터)으로 QR 주소 → 인증서 경고 없는지.
4. 계정: 팀장·담당자·검토자·관찰자 각각 로그인, 이름·새 소식 수 확인. 시연 프로젝트 `eda40175…` 선택(리허설 프로젝트와 혼동 주의).
5. 자료: 진행 중 제출물(발표 슬라이드)·완료 보고서가 보이는지, 한글 파일 다운로드 이름 확인.
6. 알림: 종 아이콘 '팀 위험 알림' 노출 여부를 A1 결정대로 확인.
7. AI: `/agent/status`가 `available:true`일 때만 시연. 호출 최대 4회, 실패 시 재시도하지 않고 수동 흐름으로 진행.
8. 종료: 시연 후 자료 보존(볼륨 유지, 필요 시 `pg_dump`), 실제 학교 제출은 하지 않음.

자동 테스트·에뮬레이션 결과는 실제 휴대폰 사용이나 학교 접수 성공을 뜻하지 않는다.
