## 검토용 초안 — 지연과 기여도

상태: DRAFT, 미적용. 생산자 B(업무·점수·알림), DB/인증 A, 소비자 C. 기존 참여 지표를 임의로 수치 점수로 바꾸지 않는다.

1. **먼저 객관적 지연 내역을 제공**: 업무명, 담당자, 합의 마감, 초과 일수, 현재 상태, 완료 요청 시각, 지연 사유. 화면 명칭은 `기한 준수`와 `지연 내역`으로 하고 지연 사실만으로 불성실을 단정하지 않는다.
2. **기준일**: 날짜 마감은 합의된 프로젝트 시간대에서 해당 날짜가 끝난 뒤부터 초과. 시간대 계약은 구현 전에 A/B/C가 확정한다. 시간 단위 표시를 원하면 별도 마감 시각 필드·시간대·기존 데이터 변환 계약이 필요하다.
3. **산식 후보(미확정)**: 기한 준수 점수 100에서 귀책 지연 1일당 5점, 업무 하나당 15점·프로젝트 합계 30점 한도로 감점. 예: 귀책 2일 지연 업무 한 개라면 90점. 참여도와 합치는 비율은 미정이며 검토 전 종합 기여도에 합산하지 않는다.
4. **승인 대기 보호**: 담당자가 결과를 제출해 완료 요청한 뒤 검토자 응답을 기다린 기간은 담당자 지연에서 제외하는 안. 반려 후 재요청은 구간별로 계산해야 하므로 현재 상태 하나만 보고 계산하지 않는다.
5. **예외**: 선행 업무 지연, 사전 합의된 기한 연장, 담당자 변경, 공동 담당자의 책임 배분은 사유와 확인자를 기록해 판정. 관찰자는 산정 대상 제외. 미배정 업무는 개인 감점 없음. 완료 후 추가 감점 없음.
6. **정정과 이력**: 팀원이 사유를 제출하고 팀장/지정 검토자가 조정. 이전 기한·담당자·감점 계산·정정 이력 보존. 본인 감점의 자의적 면제 방지를 위한 권한은 별도 합의.
7. **서버 계약 초안에서 정할 항목**: 지연 내역 조회, 계산 기준 버전, 기준 시각, 예외 사유·승인 상태, 기본/감점/최종 점수, 권한, 프로젝트 경계, 오류 응답. A가 DB 변경 필요 여부와 migration 번호를 배정한 뒤 B→C 순으로 구현.
8. **검증**: 날짜 경계, 공동 담당, 관찰자, 담당자 교체, 기한 연장, 승인 대기/반려/재요청, 재실행 중복 감점 방지, 동시 정정, 다른 프로젝트 조회/조작 거절.
