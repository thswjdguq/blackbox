로컬에서만 사용한다. 운영 비밀값이나 공개 배포 설정이 아니다.

backend 환경: SPRING_DATASOURCE_URL=jdbc:postgresql://127.0.0.1:25432/bb_expo_20261016_demo, USERNAME/PASSWORD는 기존 테스트 계정 blackbox_test, JWT_SECRET은 길이를 충족하는 테스트 전용 더미값. SERVER_PORT=18083, SERVER_ADDRESS=127.0.0.1, FILE_UPLOAD_DIR=C:/blackbox/outputs/expo-20261016/uploads. JAR는 backend/build/libs/blackbox-0.0.1-SNAPSHOT.jar.

프론트는 NEXT_DEV_BACKEND=http://127.0.0.1:18083으로 빌드했다. .next/standalone/teamplay-ui/frontend에 .next/static 및 public을 복사한 뒤 HOSTNAME=127.0.0.3, PORT=13000으로 해당 server.js를 실행한다. `next start`의 standalone 경고가 나던 이전 실행 대신 실제 standalone을 사용했다.

이미 빌드된 로컬 산출물을 다시 켜는 스크립트: `scripts/start-local-expo.ps1`. Docker Desktop과 기존 전용 테스트 컨테이너가 필요하다. 18083/13000이 사용 중이면 새 프로세스를 중복 실행하지 않는다. 실제 접속 및 계정 확인은 실행 후 수행한다. 자동 데이터 초기화/외부 배포를 하지 않는다.
