## 동작
- 공통 도우미 창에서 안내문 계획·요구사항 업무 분해·상태 요약·질문을 실행한다.
- 제출물·요구사항·업무는 사람이 제안을 읽고 고쳐 채택할 때 생성된다. AI가 완료 승인이나 요구사항 충족을 자동 처리하지 않는다.
- 실행과 제안은 프로젝트별로 구분하고 세션 변경 시 비운다. 계정 변경 이후 늦은 응답을 새 계정에 넣지 않는다.
- 채택 후 기존 화면의 목록을 갱신하고, 출처 조회 결과에 있는 기록만 AI 제안 배지를 표시한다.
- 답변 링크는 현재 프로젝트의 허용된 내부 경로만 사용한다. HTML을 실행하지 않는다.
- 원본 PR은 unavailable/조회 실패 때 진입점을 숨기지만, 별도 UI에서는 도우미를 열어 연결 전 상태를 확인할 수 있도록 진입점을 유지한다. 실행 버튼은 서버의 available/allowed 응답이 있어야 활성화한다.
