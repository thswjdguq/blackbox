# 내부 회의록 편집기

사용자 요청에 따라 UI 개선 복사본에 적용한다. C 소유 프론트에 대한 변경은 직접 요청 범위이며 통합 시 C 리뷰가 필요하다. B 소유 MeetingService의 저장 권한도 함께 보완한다. 현행 main 시연 환경은 변경하지 않는다.

## 구현

- Tiptap 편집기: 제목/본문, 굵게, 목록/번호, 체크리스트, 인용, 링크, 표, 되돌리기.
- `notes`, `decisions`를 기존 API에 마크다운 문자열로 저장. DB migration과 API 필드 추가 없음.
- 원문 보기/편집으로 기존 텍스트를 확인 가능. 회의록 양식은 빈 본문에만 적용.
- 저장 상태, 실패 시 입력 보존, 새로고침/링크 이동 시 미저장 경고.
- 노션 내보내기/노션 캘린더 버튼을 이 화면에서 제거. 기존 서버 연동이나 노션 문서는 삭제하지 않음.
- 기존 수동 업무 생성/AI 제안 기능 유지. 업무 이동 링크와 등록 완료 안내 추가.
- 관찰자 편집 비활성. 서버 회의 수정도 requireContributor 적용(기존 requireMember는 관찰자 쓰기를 허용했음).
- 공백 필드 저장은 빈 문자열을 보내 기존 내용을 지울 수 있게 수정.

## 동시 수정 제한

저장 전 GET으로 마지막 조회한 본문/결정사항과 비교하고, 이미 변경되었으면 입력을 보존하며 중단한다. GET과 PATCH 사이 동시 변경은 막지 못한다. 실시간 공동 편집/원자적 충돌 방지는 구현하지 않았으며 서버 버전 계약을 별도 합의해야 한다.

## 검증

- 타입 검사 및 프론트 운영 빌드 통과.
- `node scripts/verify-minutes-markdown.mjs`: 지원 서식 왕복 변환과 빈 문서 6개 시나리오 통과.
- `MeetingNotesTest`: 실제 ProjectAccessChecker + 저장소 mock. 멤버 저장, 팀장 내용 삭제, 관찰자 쓰기 거절/읽기 허용, 비회원 거절, 다른 프로젝트 거절 6개 테스트 통과.
- 이 단위 테스트는 PostgreSQL·HTTP·브라우저 검증과 구분한다. 실제 API 결과는 실행 후 추가한다.
- 자동 브라우저 시각/모바일/한국어 IME 입력 검증은 미완료.
- npm 설치 시 의존성 감사 22건(중간 3/높음 18/치명 1)이 보고됨. 기존과 신규의 발생 원인 비교는 미수행. 무관한 강제 버전 업데이트는 하지 않음.

## 참고

Tiptap Markdown은 공식 문서에서 Beta로 표시된다. 지원 서식에 한해 왕복 변환을 검사했으며 임의의 외부 마크다운을 무손실 변환한다고 보장하지 않는다.
https://tiptap.dev/docs/editor/markdown/getting-started/basic-usage

- 의존성 감사 상세 확인: Tiptap 및 marked 이름으로 보고된 항목 없음. 치명 항목은 기존 직접 의존성 next로 보고됨(이번 작업에서 버전 변경 없음). 감사 통과로 표현하지 않는다.


## 최종 실행 확인
- UI 개선 환경 Docker 빌드/실행 통과, nginx 새 upstream 재조회 후 health 200.
- 실제 PostgreSQL·인증 쿠키 HTTP 검증: 회원가입, 프로젝트/회의 생성, 마크다운 저장·재조회 일치, 빈 문자열로 본문/결정사항 삭제 후 null 재조회 통과.
- 검증 데이터는 별도 UI DB에만 생성. 프로젝트 b7d27942-b59c-40f8-aa43-b6dea40cd94e ([검증용] 내부 회의록). 기존 시연 DB는 변경하지 않음.


## 회의록 입력 통합 후속 변경
회의록은 편집기 하나로 통합했다. 결정사항은 AI 후보 검토 또는 선택적인 직접 정리로 저장한다. 최신 흐름과 API·검증 범위는 MEETING_OUTCOMES.md를 따른다.
