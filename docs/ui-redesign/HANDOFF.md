# UI 개선본 실행 및 검증 기록

## 최신: 결과 중심 업무 UI (2026-10-12)

- 현재 동작은 [TASK_RESULT_UX.md](TASK_RESULT_UX.md)를 따른다. 아래 초기 팀장 승인·제출물 검토 통합 기록은 당시 구현 이력이다.
- 업무 기본 화면에 완료 기준·체크리스트·결과 파일·결과 확인을 모았다. 업무 안에서 제출물 검토 회차를 여는 버튼은 제거했다.
- 담당자·요청자를 제외한 MEMBER/LEADER 한 명이 결과를 확인하면 바로 완료된다. 팀장 재승인은 없고 최종 제출물 확정은 기존 절차를 유지한다.
- 단위·회귀 55개, 타입·운영 빌드, 실제 API·DB 저장 및 권한 검사 통과. 자동 브라우저의 인증서 오류로 화면 클릭·모바일 검증은 미완료다.
- 실행 주소 https://127.0.0.2:9443 에 반영했으며 기존 main 시연 환경은 유지했다. 새 migration·원격 push·merge는 없다.

## 분리한 환경

| 용도 | 폴더 | 주소 | Compose 프로젝트 |
| --- | --- | --- | --- |
| 기존 main 시연 | C:/new teamplay | https://127.0.0.1:8443 | newteamplay |
| UI 개선 | C:/blackbox/teamplay-ui | https://127.0.0.2:9443 | teamplayui |

UI 작업 브랜치는 `codex/ui-flow-redesign`, 기준 커밋은 `98d073b`다. 원격 push/merge는 수행하지 않았다. 백엔드와 API 계약은 변경하지 않았다. 기존 시연용 폴더와 컨테이너는 수정하지 않았다.

UI 환경의 DB·업로드 볼륨은 `teamplayui_pgdata`, `teamplayui_uploads`다. 기존 데이터를 복제하지 않아 계정과 프로젝트는 독립적이다. 로컬 실행 설정과 .env는 Git에서 제외한다. 환경변수 값은 문서에 기록하지 않는다.

## 변경

- ZIP의 밝은 중성색·파란 강조색을 기존 디자인 토큰에 적용. 로그인과 회원가입도 기본 밝은 테마. 새 테마 저장 키로 기존 환경 설정과 분리.
- 사이드바를 프로젝트 진행 / 팀 협업 / 자료와 기록으로 정리.
- 파일 금고 → 프로젝트 자료, 증거 패키지 → 활동 보고서. URL과 서버 엔티티는 유지.
- 프로젝트 홈의 외부 연동 배너를 제출물·업무·검토·자료 진입 카드로 교체. 업무 비율에 근거한 정상/위험 배지 제거.
- 홈·제출물 목록·회의·자료에 공통 이동 탭 추가.
- 내 프로젝트 검색, 밝은 화면에서 카드 hover와 상태 글자 가독성 개선.
- ZIP의 브라우저 전용 인증·저장·승인 코드는 이식하지 않음.

## 재실행

PowerShell에서 `.local-run/start.ps1` 실행. 중지는 `.local-run/stop.ps1`. 중지 스크립트는 데이터 볼륨을 삭제하지 않는다.

## 검증 범위

- 최초 변경본 타입 검사 및 Docker 운영 빌드 통과, 새 환경 로그인 페이지와 `/api/health` HTTP 200.
- 세 환경(blackbox/newteamplay/teamplayui)의 컨테이너 동시 실행 확인.
- Windows 제한 실행의 로컬 빌드에서 Turbopack 자식 프로세스 오류 발생. 정상 권한 재실행 결과는 후속 기록.
- 사용자 새 주소 접속 확인. 자동화 내장 브라우저는 인증서 오류로 화면 검증 미완료. 로그인 이후 저장/권한/모바일 시연은 통과로 기록하지 않음.

## 다음 범위

손정효의 진행 중 UI 변경과 비교 후 통합한다. 이번 변경은 공통 UI와 진입 흐름 개선이며 ZIP의 모든 상세 화면을 재현한 것은 아니다. 제출물 상세·검토·확정·제출 화면의 통일 및 세 역할의 실제 시연은 후속 검증이 필요하다.

- 체크인 코드 제거·시간 기준 참석 확인, H2·H3 편집, 업무별 파일 업로드와 제출물 검토·피드백 통합을 추가했다. 변경 범위와 실제 API/DB 검증은 ATTENDANCE_AND_TASK_FILES.md 참조.
- 주요 네비게이션을 프로젝트 홈·제출물·업무·회의로 정리하고 중복 탭·프로젝트 전환을 제거했다. 상세 기준과 최종 타입/빌드/HTTP 결과는 NAVIGATION.md 참조.
- 업무에 선행 순서·완료 조건·필수 첨부와 완료 요청/팀장 승인을 추가했다. 직접 DONE 변경·요청 중 수정 우회를 막았다. 검증과 A·C 계약 검토 항목은 TASK_COMPLETION.md 참조.
