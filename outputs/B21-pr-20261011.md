## 문제와 결과

검토 피드백을 실제 업무로 옮길 때 따로 작성하면 연결이 남지 않고 중복 업무가 생길 수 있습니다. 피드백 하나를 업무 하나로 전환하고, 같은 요청을 반복하면 기존 업무를 돌려줍니다. 업무 생성·피드백 연결·활동 기록은 같은 트랜잭션으로 처리합니다.

피드백에서 만든 업무의 제출물 이동·연결 해제는 사유가 있는 409로 거절합니다. 업무 완료는 피드백을 자동 해결하지 않고 반영 확인 대기로 표시됩니다.

## 보고서에 쓸 담당 작업

검토 피드백을 업무로 전환하는 기능과 중복 생성 방지를 구현하고, 실제 DB 및 동시 API 요청으로 생성·삭제·롤백 규칙을 검증했습니다.
